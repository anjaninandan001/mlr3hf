mlr3hf

Package website: release | dev

Integration of Hugging Face datasets with the mlr3 ecosystem.

What is mlr3hf?

Hugging Face provides a large collection of datasets for machine learning and data science. mlr3hf connects these datasets with the mlr3 ecosystem.

Datasets can be downloaded from Hugging Face and converted into mlr3 data backends and tasks.

mlr3hf supports both Parquet datasets generated by Hugging Face and the original dataset files stored in a repository.

As a brief demo, we download the Iris dataset from Hugging Face, convert it into an mlr3::Task, and perform a simple resampling experiment.

hf_data <- hfdt(
  repo_id = "scikit-learn/iris",
  config = "default",
  target = "Species",
  task_type = "classif"
)

task <- as_task(hf_data)

rr <- resample(
  task,
  lrn("classif.rpart"),
  rsmp("holdout")
)

rr$aggregate()
#> classif.ce 
#>       0.02

The same dataset can also be converted directly into an mlr3::Task using tsk():

task <- tsk(
  "hf",
  repo_id = "scikit-learn/iris",

Working with Hugging Face datasets

mlr3hf provides two complementary entry points.

hfdt() creates an HFData object that provides access to the dataset and its metadata. The object can subsequently be converted into an mlr3 DataBackend or Task.

  target = "Species",
  task_type = "classif",

Loading the original dataset files

When the original files stored in a Hugging Face repository should be used instead of the generated Parquet dataset, specify file_name.

hf_data <- hfdt(
  repo_id = "scikit-learn/iris",
  file_name = "Iris.csv",
  target = "Species",
  task_type = "classif",
  primary_key = "Id"
)

hf_data$data[1:5, ]
#>    Id SepalLengthCm SepalWidthCm PetalLengthCm PetalWidthCm     Species
#> 1:  1           5.1          3.5           1.4          0.2 Iris-setosa
#> 2:  2           4.9          3.0           1.4          0.2 Iris-setosa
#> 3:  3           4.7          3.2           1.3          0.2 Iris-setosa
#> 4:  4           4.6          3.1           1.5          0.2 Iris-setosa
#> 5:  5           5.0          3.6           1.4          0.2 Iris-setosa

Depending on the arguments supplied, mlr3hf selects the appropriate loading strategy:

  • repo_id, config, target, and task_type load the dataset from the Hugging Face Parquet representation.
  • repo_id, file_name, target, and task_type load the original dataset file from the Hugging Face repository.
  • primary_key can be used to specify a column that uniquely identifies each row in the dataset.

Feature Overview

  • Hugging Face datasets can be converted directly into mlr3 Task objects.
  • Datasets can also be accessed as HFData objects and converted into mlr3 DataBackend objects.
  • Both Hugging Face-generated Parquet datasets and original canonical dataset files are supported.
  • Predefined train, test, and validation splits can be used in mlr3 resampling workflows.
  • Datasets can be searched and retrieved using list_datasets().
  • Private and gated Hugging Face datasets can be accessed using authentication tokens.
  • Downloaded datasets are cached locally to avoid repeated downloads.

Predefined Dataset Splits

Many Hugging Face datasets provide predefined train, test, and validation splits.

These splits are available through the $splits field of an HFData object and can be used to construct custom mlr3 resampling strategies.

library("mlr3learners")

hf_data <- hfdt(
  repo_id = "a4n9i/scikit_iris",
  config = "default",
  target = "Species",
  task_type = "classif"
)

task <- as_task(hf_data)

train_row_id <- hf_data$splits$train
test_row_id <- hf_data$splits$test

resampling <- rsmp("custom")

resampling$instantiate(
  task,
  train_sets = list(train_row_id),
  test_sets = list(test_row_id)
)

rr <- resample(
  task,
  lrn("classif.rpart"),
  resampling
)

rr$aggregate()
#> classif.ce 
#>  0.6333333

Listing Datasets

Datasets available on Hugging Face can be searched using list_datasets().

For example, the following searches for five datasets related to machine learning:

list_hf_data <- list_datasets(

Authentication

Authentication is required when accessing private or gated datasets.

mlr3hf looks for an authentication token in the following order:

  1. options(mlr3hf.hf_token = "...")
  2. HF_TOKEN
  3. HUGGING_FACE_HUB_TOKEN

An access token can be obtained from the Hugging Face account settings.

options(mlr3hf.hf_token = "your_api_token")

Sys.setenv(HF_TOKEN = "your_api_token")

Sys.setenv(HUGGING_FACE_HUB_TOKEN = "your_api_token")

Caching

Downloaded datasets are cached locally to avoid repeated downloads.

By default, the cache directory is:

~/.cache/huggingface/

A different cache directory can be specified with:

options(
  mlr3hf.cache_dir = "path/to/cache/directory"
)
